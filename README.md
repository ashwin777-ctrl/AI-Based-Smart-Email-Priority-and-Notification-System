# AI-Based Smart Email Priority and Notification System

An AI-based email management system that automatically analyzes incoming emails, classifies their priority, and helps users focus on important messages through intelligent notifications.

## 🚀 Features

- 📧 Email management and organization
- 🤖 AI/ML-based email priority classification
- 🛡️ Spam email detection
- 📊 Email classification and performance analysis
- 🔔 Smart notification system
- 📈 Accuracy and model performance visualization
- 🔐 User login interface
- 🌐 Web-based user interface
- 📂 Email dataset processing and analysis

## 🛠️ Tech Stack

### Programming Language
- Python

### Machine Learning
- Scikit-learn
- Pandas
- NumPy

### Web Development
- Flask
- HTML
- CSS
- JavaScript

### Machine Learning / Data
- Enron Spam Dataset
- Email classification
- Priority prediction
- Spam detection
